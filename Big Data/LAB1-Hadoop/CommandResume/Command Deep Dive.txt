create a network :
_____________________


* docker network create --driver=bridge Hadoop :

docker network create: 
set up a new communication channel.

--driver=bridge:
defines the type of network

hadoop: 
name of bridge 


---------------------------------------------------------------------------------


* docker run -itd --net=hadoop -p 50070:50070 -p 8088:8088 -p 8080:8080 --name hadoop- master --hostname hadoop-master liliasfaxi/spark-

create a Master Node (Namenode)
-itd : 
  -i:(interactive)  Keeps the "input" open so you can send commands to it later
  -t:(tty) virtual  terminal => real Linux machine
  -d:(detached)     run in the background
-p (Port Mapping)
  -p 50070:50070 : HDFS Web UI => see Datanodes
  -p 8088:8088   : YARN Resource Manager UI => see MapReduce jobs
--net=Hadoop : plugs master to network created before 
--name : what Docker calls the container
--hostname : what the Hadoop calls the machine
